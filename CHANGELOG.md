# Changelog

## 0.1.0

- Initial Themora release: global and scoped CSS-token themes, persisted system preference, native transitions, procedural analog TV static, `changeOnVisit`, and optional React/Vue/Next adapters.
- Dual ESM/CommonJS conditional declarations and independently importable effect entry points.
- Snapshot-based crossfade, ripple, wind, and genuine animated wave fallbacks.
- Concurrent scoped transitions, cancellable dynamic section registration, CRT reveal origins, speed/delay controls, and opt-in static audio.
